## 1) How `terraphim-agent` decides which roles appear in `roles list`
`terraphim-agent roles list` is driven by whatever `Config` it successfully **loads at startup**. In *offline* mode, the agent initializes like this:

- It always builds a config object with `ConfigId::Embedded`
- Then it tries to **load** persisted config for that ID (`embedded_config.json`)
- If loading fails, it falls back to `build_default_embedded()` which hardcodes 3 roles:
  - `Default`
  - `Terraphim Engineer` (KG local path default: `docs/src/kg`)
  - `Rust Engineer`

Source: `crates/terraphim_agent/src/service.rs` and `crates/terraphim_config/src/lib.rs` (`build_default_embedded`).

So: to make **multiple custom roles show up**, you must ensure the persisted config that gets loaded (for the embedded ID) contains those roles.

## 2) Where that config is loaded from (and the key filename)
The config is stored/loaded via the persistence layer (`terraphim_persistence::Persistable`). The filename key for Embedded is:

- `embedded_config.json`

Specifically:
```rust
ConfigId::Embedded => "embedded_config.json"
```
Source: `crates/terraphim_config/src/lib.rs` → `Persistable for Config` → `get_key()`.

## 3) What env var / settings path controls where it persists
Persistence uses `DeviceSettings`, which are loaded via:

- `DeviceSettings::load_from_env_and_file(None)?;` (agent side)
- and inside persistence init it checks:
  - `TERRAPHIM_SETTINGS_PATH` (if set, uses it)
  - otherwise defaults to `crates/terraphim_settings/default` (in-repo dev default)

Source: `crates/terraphim_persistence/src/lib.rs`:
```rust
let settings_path = std::env::var("TERRAPHIM_SETTINGS_PATH")
  .map(PathBuf::from)
  .unwrap_or_else(|_| PathBuf::from("crates/terraphim_settings/default"));
```

This means: **your installed musl binary** will look for settings in its default location unless you override with `TERRAPHIM_SETTINGS_PATH`, and those settings determine the “data dir” where `embedded_config.json` is stored.

## 4) Why you see the “missing docs/src/kg” issue
The embedded default role `Terraphim Engineer` uses:
- `knowledge_graph_local.path = "docs/src/kg"`

That path exists in the repo dev environment, but **won’t exist** for an installed binary unless you create it or override the config.

Source: `build_default_embedded()` in `crates/terraphim_config/src/lib.rs`.
