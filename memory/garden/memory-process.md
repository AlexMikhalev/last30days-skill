# Memory process (stream → garden)

## Principle
- **Daily notes** (stream) are capture.
- **Garden notes** (concept notes) are retrieval.
- **MEMORY.md** is a curated *executive summary* of durable facts/decisions.

## Workflow
1) Capture raw items in `memory/YYYY-MM-DD.md`.
2) Promote durable items into a concept note under `memory/garden/`.
3) Keep a short pointer in the daily note (optional): `Promoted to: [[jibble]]`.
4) Periodically prune/merge garden notes so each topic has a single source of truth.

## What gets promoted
- Decisions, commitments, rules, stable links, procedures, definitions.

## What stays in the stream
- Transient chatter, tentative ideas, one-off observations.
