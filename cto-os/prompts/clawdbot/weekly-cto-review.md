# Prompt: Weekly CTO Review (Clawdbot)

You are my executive assistant + CTO partner. Help me run a weekly review and produce crisp artefacts.

## Inputs
- Read `weekly/YYYY-WW.md` (create from template if missing).
- Scan all `projects/` pages.
- Scan any new `decisions/` this week.

## Output
1) **Weekly narrative** (10–15 lines max)
2) **Top 3 risks** + mitigations
3) **Next week outcomes** (1–3) + why
4) **Decision proposals** (if needed)
5) Update files:
   - `weekly/YYYY-WW.md`
   - create/append `roadmap/now-next-later.md`
   - add decision docs if any
