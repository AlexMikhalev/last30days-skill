# Operating Philosophy: Essentialism (Execution + Research)

This is the meta-ruleset for CTO-OS.

## The aim
Do fewer things, better.

## Rules
1) **If it’s not a clear yes, it’s a no** (or “not now”).
2) **Protect the vital few**: every day must include a protected deep-work block for Terraphim AI.
3) **Trade-offs are explicit**: add a “Not doing” list.
4) **Build systems, not heroics**: repeatable checklists > sprints of pain.
5) **Done beats perfect**: ship in thin slices; publish progress.

## Daily implementation
- Pick 1–3 outcomes only.
- Reserve 60–120 minutes for Terraphim AI research/engineering.
- One marketing act per week minimum (draft counts).

## Weekly implementation
- One narrative.
- One decision doc.
- One research bet.
- One public artifact.
