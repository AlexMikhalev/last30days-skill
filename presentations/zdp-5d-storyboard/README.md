# Zestic 5D / ZDP — Interactive presentation (Reveal.js)

## Open locally

On your machine:

```bash
cd /home/alex/clawd/presentations/zdp-5d-storyboard
python3 -m http.server 8009
```

Then open:
- http://localhost:8009

## Controls
- Arrow keys: navigate
- `O`: overview
- `S`: speaker notes

## Notes
- Uses Reveal.js + Mermaid via CDN (no build step).
- If you want a PDF export, open in Chrome and Print → Save as PDF.
